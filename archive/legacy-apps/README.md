## Articulación
Antes de archivar se verificó que las correcciones históricas relevantes de Mapa de la Oferta siguen presentes en el main actual, mediante versiones más nuevas de:
- src/v33-articulation-rules.js
- src/v21-custom-social-ui.js

El main actual conserva:
- articulación FG ↔ FO desde Nivel 3 dentro del mismo nivel;
- control de máximo de 9 HC;
- soporte táctil/móvil;
- articulación de materias agregadas por la escuela con espacios del mismo año;
- opciones de Ciencias Sociales N3 de 10 o 12 laboratorios;
- validación específica para Sociales N3 cuando parte de sus materias se articula con FO.

No usar estos HTML históricos como punto de entrada productivo.
